# Capturas del dashboard

Coloca aquí las dos imágenes que referencia el README principal:

- `dashboard.png` — vista general del dashboard (mapa de estaciones, serie de
  tiempo y tarjeta del día).
- `chat_agente.png` — una conversación con el agente mostrando las herramientas
  usadas y las fuentes citadas.

Para generarlas: lanza `streamlit run app.py`, toma las capturas y guárdalas en
esta carpeta con esos nombres exactos.
